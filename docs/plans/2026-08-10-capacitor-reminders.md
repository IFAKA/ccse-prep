# Capacitor Android Reminders Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Package the existing CCSE Prep PWA as an Android app with reliable local study reminders, while preserving its local-first IndexedDB data model.

**Architecture:** Keep the existing Next.js/React UI and question bank. Add Capacitor as the Android shell, expose a small browser-safe reminder service backed by Capacitor Local Notifications when native and the Web Notifications API when running as a PWA, and keep widget work as a second milestone after notification behavior is validated on the Redmi Note 14 5G. The native build must use a static web bundle; the existing optional sync API remains a hosted-web capability and is not treated as native local storage.

**Tech Stack:** Next.js, React, TypeScript, Capacitor, Capacitor Local Notifications, IndexedDB, Android/HyperOS.

---

### Task 1: Add Capacitor project configuration

**Files:**
- Create: `capacitor.config.ts`
- Modify: `package.json`
- Modify: `next.config.mjs`

Install current Capacitor core, CLI, Android, and Local Notifications packages. Configure app id/name and `webDir: "out"`; enable static export only after confirming the API route and redirects are handled safely.

### Task 2: Add a platform-safe reminder service

**Files:**
- Create: `src/lib/reminders.ts`
- Create: `tests/reminders.test.ts`

Define typed reminder input and functions to request permission, schedule/cancel a daily reminder, and schedule a due-review reminder. Use dynamic Capacitor imports so web builds do not require native globals. Keep scheduling independent from the event reducer and IndexedDB state.

### Task 3: Add reminder settings behavior

**Files:**
- Modify: `src/lib/types.ts`
- Modify: `src/lib/events.ts`
- Modify: `src/components/SettingsView.tsx`
- Modify: `src/components/AppShell.tsx`

Add opt-in reminder settings with a native checkbox/time input, persist them through the existing event log, and reschedule after state load or settings changes. Provide an accessible live status and a browser fallback message where native scheduling is unavailable.

### Task 4: Generate and sync the Android project

**Files:**
- Create: `android/`
- Create: `pnpm-lock.yaml` updates as generated by package installation

Run the Capacitor Android add/sync flow and verify the generated project has notification permission handling and a release-safe configuration. Do not add a widget in this milestone.

### Task 5: Validate the web and native boundary

Run:

```bash
npm run lint
npm run typecheck
npm test -- --run
npm run build
npx cap sync android
```

Expected: lint, typecheck, tests, and the production web build pass; Capacitor sync completes. Device install and notification delivery on the Redmi remain a required manual check before adding a home-screen widget.
